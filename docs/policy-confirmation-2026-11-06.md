# ERP 완성을 위한 미답변 정책 확인표

2026-11-06 / Asia/Seoul. P1 실행 산출물 초안. [통합계획](completion-plan.md)의 Q1~Q7을 [최신 결정](07-decisions.md), [요구사항](01-requirements.md), [04 준비표](phase-04-preparation.md), [예산 정책](budget-policy.md), 단계 04~10 및 현재 코드와 대조했다. **추천안은 사용자 답변을 받기 전까지 미확정이며 현재 제출·승인·지급을 활성화하는 근거가 아니다.**

## 0. 같은 날 사용자 후속 답변

## 2. 지금 필요한 답변 — Q1/Q2

답변은 정책 선택·근거 위치만 적고 실제 사람·계좌·증빙·인증정보는 넣지 않는다. 현재 수치가 정해지지 않았다면 ‘확인 필요’로 남길 수 있다. 그 답은 해당 경로를 미완료로 유지한다는 뜻이며 무제한 또는 허용으로 간주하지 않는다.

### Q1. 유형별 상세 입력·필수서류 최종 적용

현재 EX-07은 B-01~B-09의 **채택 의향만 기록**했고 최종 적용은 보류했다. 기존 추천표를 새로 기관 규정이라고 선언하지 않고 최종 채택/수정/보류를 답변받아야 한다.

| 항목 | 필요한 결정 | 추천안과 영향 | 답변란 |
|---|---|---|---|
| Q1-01 B-01~09 | [준비표](phase-04-preparation.md)의 유형별 추가 입력·신청 시/승인 전 자료·조건을 최종 적용할지 | 기존 표를 기준으로 번호별 수정만 받는 방식을 추천. 최종 채택된 행만 필수값·누락 판정에 적용. 보류 행은 그 유형의 전체 제출/승인 완료로 간주하지 않음 | 미답변: 일괄 채택 / 일부 수정(번호·내용) / 보류 유지 |
| Q1-02 연구인력지원비 | 실제 지원 대상/성격이 인건비·수당·장학 등 중 무엇인지, 허용 범위와 근거 | 성격별 필드·서류·공제 필요가 다르므로 지원 유형을 명시하는 방식을 추천. 실제 근거 없는 세율·자격·중복지원 제한은 만들지 않음 | 미답변: 허용 성격·대상 / 근거 / 제외 범위 |
| Q1-03 B 공통 세부안 | 이미 확정된 제출 시점 외의 B 공통 제안(예정/실제 정보 보완, 증빙 역할 연결 등)을 채택할지 | 같은 파일이 여러 서류 역할을 충족하면 중복 업로드 없이 연결하는 방식 추천. 개인정보 상세를 일괄 필수로 추가하지 않음 | 미답변: 채택 / 수정 / 보류 |

외부전문기술활용비에 전문가 자문·업체 기술지원이 포함된다는 답은 유지한다. 그 밖의 범위가 필요할 때만 추가 답변을 받고 기존 포함 범위를 다시 묻지 않는다.

### Q2. 기준 미확인·초과·적용 기준일

기준 자체가 미확인인 상태와 필수 증빙이 누락된 상태는 다르다. 후자의 승인 차단은 이미 확정되어 있다.

| 항목 | 필요한 결정 | 추천안과 영향 | 답변란 |
|---|---|---|---|
| Q2-01 기준 미확인 제출 | 실제 단가/한도/기한 기준이 확인되지 않은 유형의 신청 제출 허용 여부 | ‘확인대기 표시 후 제출·담당자 검토는 허용’하는 방안을 제안. 이 경우 제출 시 차감은 동일하며 확인대기가 면제/적격을 뜻하지 않도록 표시. ‘제출 차단’을 선택하면 초안만 가능 | 미답변: 확인대기 제출 허용 / 제출 차단 / 보류 |
| Q2-02 기준 미확인 승인 | 기준이 아직 미확인인데 내부 최종 승인을 허용할지 | 근거·적용 기준이 확인될 때까지 승인 차단을 추천. 예외 허용이 필요하면 권한·사유·증거·유효범위를 별도로 결정해야 하며 담당자가 임의 해제하지 않음 | 미답변: 확인 전 승인 차단 / 명시 조건부 허용(조건) / 보류 |
| Q2-03 확인된 상한 초과 | 초과 건의 제출 차단 또는 검토 접수 허용과 승인 조건 | 초과 표시와 제출 차단을 우선 제안. 기관 근거가 검토 접수를 허용하면 초과 경로·승인 가능 조건을 명시. 검토 접수 허용을 상한 무시 승인 허용으로 해석하지 않음 | 미답변: 제출 차단 / 검토 접수 허용(승인 조건) / 보류 |
| Q2-04 적용 기준일 | 신청일/예정·실제 사용일/계약일 등 어떤 사건으로 기준 버전을 고르는지 | 유형·근거별 기준 사건을 설정하고 신청에 적용한 버전을 고정하는 방식 추천. 날짜 보완 시 재판정·이력 조건도 함께 정의. 보편 기준일은 임의 선택하지 않음 | 미답변: 유형별 기준 사건·근거 / 날짜 변경 시 처리 |
| Q2-05 실제 수치·기한 | 각 적용 유형의 단위·단가·건별/기간별 한도·기한·영업일/달력일·시행 기간·근거 | 확인된 수치만 설정하고 근거 문서명/버전/항목/시행일과 연결. 수치 초기값이나 세율을 임의로 추천하지 않음 | 미답변: 비공개 근거 위치·유형별 값 / 확인 필요 |

Q1/Q2가 미답변이면 관련 검증·제출·승인을 임의 활성화하지 않는다. 공통 화면·정책 버전 계약·가상 검사 설계처럼 답변에 의존하지 않는 P2와 독립 작업은 계속한다.

## 3. 후속 단계에서 필요한 답변 — Q3~Q7

현재 관련 없는 질문 때문에 독립 구현을 멈추지 않는다. 아래 항목은 명시한 단계의 기능·운영을 활성화하기 전에 필요한 범위만 묶어 확인한다.

### Q3. P4/P5의 상세·추가/분할·대행·실청구 묶음

근거: D-08, EX-02. ‘한 신청당 예산항목 1개’는 질문 대상이 아니다.

| 항목 | 필요한 결정 | 추천안과 영향 | 답변란 |
|---|---|---|---|
| Q3-01 상세행/추가 신청 | 한 신청 안에 같은 예산항목을 사용하는 복수 산출행이 필요한지, 추가 지출은 새 신청인지 | 복수 산출행은 동일 항목 내 합계로만 취급하고 추가 지출은 원건 연결이 있는 새 신청으로 구분하는 안을 제안. 새 신청이면 새 잔액 검사·차감, 기존 신청 수정이면 복귀·복원·재신청 원칙 적용 | 미답변: 상세행 필요 여부 / 추가·분할 신청 방식 |
| Q3-02 실청구 묶음 | 내부 신청 여러 건을 하나의 대학 ERP 문서와 연결할 필요가 있는지, 한 신청을 여러 실청구 시도/문서에 배분하는지 | 외부 문서와 신청의 관계/배분만 별도 보존하고 신청금액·원 차감은 덮어쓰지 않는 안을 제안. 중복 문서/반려·재상신 시도와 실제 지급을 구분 | 미답변: 단건 / 여러 신청 묶음 / 여러 문서 배분(조건) |
| Q3-03 대행 범위 | 담당자의 연구원 대신 초안 작성·제출·보완 범위와 필수 사유 | 담당자가 본인 권한 안에서 원 업무 주체·실제 행위자·사유를 함께 남기는 방식 추천. ‘담당자가 전체 업무 관리’라는 일반 권한으로 개별 대행 절차를 모두 확정하지 않음 | 미답변: 허용 행위·대상·사유/증거 |

### Q4. P5의 실제 지급·환입·정정·마감

근거: D-08/D-09. 실제 지급 기록은 송금 기능이 아니며 승인값으로 자동 생성하지 않는다.

| 항목 | 필요한 결정 | 추천안과 영향 | 답변란 |
|---|---|---|---|

## 6. 답변 기록과 자동 진행 판정

- 위 답변 기록이 없는 ‘미답변’란은 미확정이다. 제0절의 명시 답변 범위만 후속 확정으로 처리하며, 문서 작성만으로 실제 수치·기관 사실을 채택하지 않는다.
