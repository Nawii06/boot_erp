## 세션·복구 및 계정 운영 확정 — 2026-10-05

사용자가 “세션·복구 안내는 정리된 추천과 같이 정리하여 사용”을 지시하고 가입·관리자 계정 관리·허용 이메일에 답변했다. AC-07의 미결정 상태를 아래 기록으로 대체하며 기존 행은 보존한다.

| ID / 관련 결정 | 상태 | 확정 내용 |
|---|---|---|
| AC-08 / D-05, S-01~S-10 | 확정 | 세션·복구 권고안 채택: 유휴 15분, 최대 8시간, 2분 전 경고, 장기 로그인 미제공, 동시 2세션과 초과 신규 접속 제한, 현재/전체 기기 로그아웃, 정지·역할·인증 연결 변경 시 세션 폐기, 민감 계정관리 전 최근 5분 이내 추가 본인 확인. Google 계정은 Google 복구, 일반 ERP 계정은 담당자 확인·관리자 대행 및 감사 이력 |

[확정 정책](auth-policy.md)에 수기 확인 대상·확인자·시각·방법·결과를 기록하고, 사전 등록/수기 확인/Google 인증을 각각 검사하는 구현 방침을 정리했다. 확인 대기·실패 시 로그인 불가, 이메일 변경·연결 복구 시 재확인한다. 부재 시 관리자의 일반 계정 대행은 AC-02를 유지한다. 수기 확인을 자동 메일 연동 또는 실제 확인 수행 완료로 표현하지 않는다.

D-04/D-05의 02 진입 정책은 확정됐다. 추가 본인 확인 수단의 기술 검증, Google OAuth 실행 설정, 최초/긴급 관리자 복구 절차와 장애 대응은 구현·운영 준비 사항으로 남는다. 이번은 정책 문서 갱신이며 실제 기능 구현·검수는 미수행이다. [후속 작업기록](history/2026-10-05-phase-02-session-confirmed.md) 참고.
