서버 검수는 [A-01~A-12](06-acceptance.md)의 02 대표 경로를 대상으로 한다. 미구현 증빙·청구·지급·보고서 기능의 검수까지 완료했다는 뜻은 아니다. 대학 SSO 교체는 가상 제공자로 내부 ID/이력 보존을 검수했으며 실제 기관 연결은 별도다.

## 지금 가능한 업무

1. `http://localhost:3000`에서 사전 등록·수기 소유 확인·활성화를 마친 Google 계정으로 로그인한다.
2. 담당자/관리자는 추가 본인 확인 후 계정을 관리하고, 과제·비교과와 참여자를 등록한다.
3. 참여 연구원에게 업무를 배정하고 책임자가 담당 과제·비교과를 조회한다.
4. 담당자가 바뀌면 업무를 재배정하고 기존 내용·원 작성자·변경 사유를 보존한다.
5. 담당자가 예산을 최초 배정하고 연구원은 담당 과제의 항목 간 변경을 신청한다. 담당자·관리자가 검토·확정하며 총액 증감 신청은 담당자만 한다. 첨부·상세에는 현재 권한을 적용한다.

계정당 역할은 1개다. 일반 계정은 담당자 우선·관리자 대행, 관리자 계정은 관리자만 관리한다. 연구원은 같은 과제라도 동료 업무를 볼 수 없다. 책임자는 업무 조회 전용이다. 정책을 다시 미결정으로 돌리거나 반복 승인받지 않는다.
