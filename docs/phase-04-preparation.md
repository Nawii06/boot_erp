# 04단계 사전 준비표

점검일: 2026-10-18. **03 구현·검수 완료 → 04 준비 점검 완료·업무별 입력 대기 → 04 기능 미착수**다. [03 완료 재점검](history/2026-10-18-phase-03-close-review.md)과 [04 단계 계획](stages/04-pre-requests-evidence.md)을 함께 읽는다.

## 다시 결정하지 않아도 되는 사항

- 로그인·역할·연구원 간 개별 업무 비공개·책임자 조회 전용·동일 업무 인수인계는 확정됐다.
- 신청 즉시 차감, 처리 전 본인 회수, 보완 중 차감 유지, 복원 후 금액 수정·재신청, 지급 전 담당자·관리자의 승인 후 취소는 확정됐다.
- 담당자 승인으로 내부 승인 완료다. 외부 공식 승인 상태·문서번호를 필수 단계로 추가하지 않는다. 실제 지급은 별도다.
- 사업명·연차·공통 예산 사용기간·Notion 우선 분류·코드는 확정됐다. 실제 예산 DB 입력은 아직 하지 않았고 가상 구현의 차단 조건이 아니다.
- 예산변경 양식을 첨부로만 받는 정책은 확정됐다. 모든 지출 유형의 필수 증빙 목록이 확정된 것은 아니다.

## 준비 순서

| 순서 | 준비할 내용 | 현재 판단·담당 |
|---|---|---|
| 1 | 처음 사용할 지출 유형 목록 | 사용자/업무 담당자 확인. 회의비·출장비 등은 예시이며 현행 전체 목록이 아님 |
| 2 | 유형별 입력항목·필수서류·제출 시점·조건 | D-07 확인 필요. 예산 분류와 지출 유형을 구분해 개발자가 표로 대조 |
| 3 | 신청 1건의 예산항목 수와 선택 범위 | D-08 중 04에 필요한 부분만 사용자 확인 |
| 4 | 실제 사용하는 서식·지침의 버전·적용일·단가/기한 유무 | 기존 자료를 우선 재사용하고 업무 담당자가 최신성·적용 여부 확인 |
| 5 | 증빙의 파일 형식·용량·복수 파일·ZIP 처리 | 03 기술 한도와 구분해 사용자 필요량 확인 후 설계 |
| 6 | 가상 신청→차감→검토→보완→승인/복원 검수 자료 | 개발자가 준비 가능. 실제 개인정보·계정 추가·예산 이관 불필요 |

### 서류 제출 시점

서류마다 신청 시 필수인지, 담당자 승인 전 필수인지, 특정 조건에서만 필요한지 구분한다. 준비되지 않은 서류 때문에 신청을 불필요하게 막거나 필수서류 없이 승인하는 일을 방지하기 위한 기준이다. 서류 누락 시 차단할 단계는 아직 확정하지 않는다.

### 신청 범위

- **신청 1건에 예산항목 1개 또는 여러 개**: 현재 03 공통 서비스는 1개다. 초기 04도 1개로 시작하는 방안을 권고하지만 사용자 확정은 아니다. 여러 개라면 배분 합계·원자적 차감/복원 확장이 선행되어야 한다.
- **지출 신청의 항목 선택**: 본인 배정 업무와 같은 과제의 항목 전체인지, 담당자가 업무별로 지정한 항목만인지 확인한다. 현재 서비스는 배정 업무·같은 과제를 검사하며 업무별 예산항목 허용표는 없다. 연구원의 과제 전체 예산변경 권한과 개별 지출의 항목 선택 권한을 혼동하지 않는다.
- **업무 날짜**: 예산 사용기간은 확정이다. 사용 예정일/실제 사용일, 뒤늦은 등록·기간 밖 사용 등의 처리 기준이 필요하면 근거를 확인한다. 현재 공통 서비스의 제출일 기간 검사를 실제 사용일 검증 완료로 간주하지 않는다.

### 근거 자료와 파일

[자료 목록](08-sources.md)의 S-03~S-06 등 기존 제공 자료를 우선 대조한다. 목록은 사본의 식별 기록이며 최신 개정본·모든 지출 유형의 기준 확인 완료를 뜻하지 않는다. 변경된 자료만 추가로 확보하고 원문은 비공개 위치에서 읽는다. 확인되지 않은 단가·한도·기한을 임의 수치로 만들지 않는다.

03 예산변경 첨부는 파일당 최대 5MiB, PDF·이미지·한글·Office 계열을 지원한다. 04의 출발점으로 검토할 수 있으나 실제 스캔 용량·필요 파일 수를 확인해야 한다. 지출 증빙은 서류별 복수 파일과 이전 제출본 보존이 필요하다. ZIP 지원 여부는 별도 확인하며 ZIP 1개가 필수서류 전체 충족을 뜻하지 않는다. 운영 보존기간·검역·성능·백업 복구는 후속 운영 준비에서 결정한다.

## 답변 입력 양식

실제 개인정보·증빙 내용 대신 업무 기준을 기입한다. 예시·권고를 확정값으로 채우지 않는다.

```text
[04 기본 범위]
처음 사용할 지출 유형 목록:
신청 1건의 예산항목: 1개 / 여러 개
지출 시 선택 범위: 배정 업무와 같은 과제의 항목 전체 / 업무별 지정 항목
기존 제공 자료의 최신본 여부: 그대로 사용 / 변경됨(변경 자료만 기재)
필요 파일 형식:
파일당 최대 크기와 예상 파일 수:
ZIP 제출 필요 여부:

[유형별 기준 — 유형마다 반복]
지출 유형명:
신청 시 입력할 내용:
필요 서류명:
서류 제출 시점: 신청 시 / 담당자 승인 전 / 조건부
조건부라면 적용 조건:
단가·한도 기준: 있음(근거 기재) / 없음 / 확인 필요
신청·사용·증빙 제출 기한: 있음(근거 기재) / 없음 / 확인 필요
근거 자료명·버전·적용일:
기존 서식 사용 방식: 파일 첨부 / 화면 입력 필요 / 확인 필요
개인정보 없는 빈 서식의 비공개 위치(있으면):
```

## 이후 작업

개발자가 답변과 기존 근거를 대조해 확정값·제안·미결정을 기록하고, 입력 필드와 03 서비스 확장 필요 여부·지출 증빙 권한을 설계한다. 자료 대조·설계·가상 검수 준비는 지금 가능하다. 실제 필수서류·차단 조건을 임의 확정하지 않는다. 04 구현 지시 후 기본 신청·증빙 화면과 관련 검수를 진행하며 05·06·실자료 이관으로 자동 확대하지 않는다.
