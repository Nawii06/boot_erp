## S-07: 기존 Notion 예산관리 페이지

사용자가 제공한 비공개 업무 페이지를 읽기 전용으로 검토했다. 공개 문서에는 원본 URL·개인 이름·연락처·학번·개별 청구금액을 게시하지 않는다. 원본 접근 위치는 권한 있는 내부 보관소에서 관리한다.

확인한 내용:

- 프로젝트·예산배정·예산사용·예산변경요청·연락처의 5개 DB 구조
- 예산사용의 요청/사용확정/반려와 별도 ERP등록 체크 항목
- 회의비·학생출장비 양식의 사전 협의 및 사후 증빙 제출 구분
- 예산변경 대상 항목의 직접 연결, 제출본 이력, 실제 지급기록을 ERP에서 보완할 필요

확인하지 못한 내용:

- 일부 버튼·자동화의 실제 동작과 수식 원문·최종 계산결과
- 전체 원본 행·첨부자료의 누락 없는 확보 여부와 실제 지급 대조
- 기존 Notion의 사용자별 실제 권한·공유 설정
- 안내 문구의 모든 단가·기한과 최신 규정의 일치 여부

현재 운영 Notion이 잘못되었다고 단정하지 않는다. 이번 검토는 ERP 설계에 필요한 구조·사례 검토이며 회계감사나 전체 잔액 검증이 아니다.
