# 04단계 — 단일 지출 신청·증빙 기반

2026-10-18 사전 준비 점검: [확정 예산 정책](../budget-policy.md)에 맞춰 초기 초안을 정리했다. 사전/사후 분리·검토 완료 후 최초 차감·외부 공식 승인 기록 의무는 적용하지 않는다. 파일명은 기존 링크 호환을 위해 유지한다. [04 사전 준비표](../phase-04-preparation.md)를 먼저 확인한다.


상태: 2026-10-20 공통 운영·설정 구성 확정, B 채택 의향 기록·최종 결정/적용 보류·기능 미착수 / 목표: 연구원이 배정 업무의 지출을 신청하고 담당자가 내용과 증빙을 검토하게 한다.

EX-01~EX-11로 지출 유형 9종·신청 범위·공통 입력·증빙 시점·파일 운영·현재 적용 자료, 설정 구성·관리 권한과 기준 미확인 시 초안 허용을 기록했다. B 세부 입력·필수서류는 채택 의향만 기록하고 적용을 보류한다. 연구인력 범위·실제 단가/기한·적용 기준일·미확인 상태의 제출/승인·초과 처리는 미결정이다. 설정 구현 시점은 후속 설계에서 정리한다.

## 선행조건

03단계 완료 증거와 `../STATUS.md`를 확인한다. `../07-decisions.md`에서 이 단계에 필요한 정책이 결정되었는지 확인한다. 이전 단계의 미해결 중대 결함이 있으면 관련 구현을 먼저 해결한다.

03 구현·가상 검수 완료는 [재점검 기록](../history/2026-10-18-phase-03-close-review.md)을 따른다. 유형별 B 입력·증빙은 사용자가 차후 결정하기로 했으므로 적용하지 않는다. 이번 기록 작업으로 04 구현을 시작하지 않는다.

## 개발 범위

- 지출 유형·필수 입력항목·조건부 증빙 설정을 담당자 업무 설정으로 만든다.
- 배정 업무의 단일 신청 초안·제출·조회·처리 시작·회수·보완·담당자 내부 승인 화면을 구현한다.
- 담당자 승인을 내부 승인 완료로 기록한다. 외부 공식 승인 상태·문서번호를 필수 단계로 추가하거나 승인을 실제 지급으로 처리하지 않는다.
- 03 금액 서비스에 신청 제출·차감을 원자적으로 연결한다. 보완은 차감 유지, 적법한 복귀는 복원, 금액 변경은 복원 후 수정·잔액 검사·재신청으로 처리한다.
- 비공개 파일 저장·접근 검사·서류별 제출/검토 상태·파일 교체이력을 구현한다.
- 연구원 간 개별 업무 격리·책임자 조회 전용·후임 자료 승계를 목록·상세·파일·검색에 적용한다. 원 작성자와 대행 행위자를 보존한다.

03 첨부는 예산변경 건에 귀속된다. 지출 신청용 증빙·서류 종류·제출본은 04에서 추가해야 한다. 현재 지출 공통 서비스는 예산항목 1개와 본인 배정 업무·같은 과제를 검사한다. 이 범위는 A-02/A-03으로 채택됐으며 업무별 항목 허용표나 다중 항목 차감을 추가하지 않는다. 파일당 5MiB·신청당 10개·합계 20MiB와 ZIP 미지원을 지출 증빙에서 구현·검수한다.

04는 기본 신청·증빙·처리 화면을 만들고, 05는 동일 신청의 상세 청구내역·서류별 보완 왕복·금액 정정·대행 범위를 확장 검수한다. 별도 사후 신청을 생성하여 다시 차감하지 않는다. 관련 D-08 범위는 해당 기능 전에 확인한다.

## 이 단계의 특이사항

Notion 양식의 단가·3일 전 안내 등을 현재 공식 규칙으로 자동 확정하지 않는다. D-07의 근거·시행일이 있는 기준만 사용한다. ZIP은 초기 미지원으로 확정됐다. 예산변경의 첨부 정책을 모든 지출 증빙의 필수 목록으로 확대하지 않는다. A-10의 현재 적용본 확인과 개별 수치·조항 대조 완료를 구분한다.

## 산출물

- 단일 지출 신청·보완·내부 승인·제출본 이력 화면
- 유형별 입력/증빙 설정과 비공개 파일 모듈
- 신청 차감·복원 연결과 파일 권한 검수
- 공통: `docs/STATUS.md`, `CHANGELOG.md`, `docs/history/YYYY-MM-DD-phase-04.md` 갱신

## 완료 기준

- W-01/W-02와 F-01~F-03을 확인한다.
- 연구원은 배정 업무의 허용 예산항목만 선택한다.
- 제출 단계에서 예산이 부족하면 신청 상태·차감·감사가 부분 반영되지 않는다.
- B-01/B-09/B-10/B-11/W-05의 공통 서비스 검수를 관련 화면에 연결한다. 파일의 타인 접근·배정 해제·후임 승계·교체 이력을 검증한다.
- ZIP 미지원이면 거부 동작과 범위를 기록하고 ZIP 지원 검수 완료로 표시하지 않는다.
- 연결 검수: W-01, W-02, F-01~F-03. [전체 검수표](../06-acceptance.md)에 실제 결과를 연결한다.
- 실패·미실행·미결정을 기록하고 다음 단계 진입 가능 여부를 보고한다.

## 이번 단계 제외

외부 공식 결재 상태 관리·자동 상신, Notion 변경·자동 연동, 실제 지급·환입·운영 배포·실자료 자동 이관.
