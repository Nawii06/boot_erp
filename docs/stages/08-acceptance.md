# 08단계 — 통합·권한·금액 인수검수

상태: 미착수 / 목표: 실제 업무에 투입할 수 있는지 가상 데이터로 전체 흐름을 검증한다.

## 선행조건

07단계 완료 증거와 `../STATUS.md`를 확인한다. `../07-decisions.md`에서 이 단계에 필요한 정책이 결정되었는지 확인한다. 이전 단계의 미해결 중대 결함이 있으면 관련 구현을 먼저 해결한다.

## 개발 범위

- 4종 역할과 여러 프로젝트를 이용해 핵심 사용자 여정을 수행한다.
- 단계별 검수를 회귀 실행하고 권한·동시성·중복·파일·금액 경계 사례를 검증한다.
- 담당자 관점에서 서식·문구·업무 순서를 대조한다.
- 합의한 사용자 수·파일량·성능 목표를 시험하고 오류·대기·실패 화면을 확인한다.
- 결함 목록을 중요도·재현법·해결상태로 기록하고 실자료 시험 진입 여부를 판단한다.

## 이 단계의 특이사항

화면이 열리는 것만으로 ERP 검수 완료라고 하지 않는다. 실패 테스트를 건너뛰거나 실제 개인정보를 공개 테스트 결과에 포함하지 않는다. 검수 미통과를 배포로 해결하려 하지 않는다.
