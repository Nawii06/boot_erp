# 09단계 — 자료 이관 준비·제한 시범운영

상태: 미착수 / 목표: 원본을 보존하면서 필요한 기존 자료를 대조·이관하고 운영 적합성을 확인한다.

## 선행조건

08단계 완료 증거와 `../STATUS.md`를 확인한다. `../07-decisions.md`에서 이 단계에 필요한 정책이 결정되었는지 확인한다. 이전 단계의 미해결 중대 결함이 있으면 관련 구현을 먼저 해결한다.

## 개발 범위

- 대상·기준일·원본 접근·비공개 보관소를 확정한다.
- 원본 상태·ID를 보존하는 매핑, 임시 이관 영역, dry run, 오류 목록을 만든다.
- 현재예산 기준 이관과 변경이력 재구성을 혼용하지 않고 기초잔액 방식을 정한다.
- 원본 건수·금액·관계·파일을 대조하고 검증된 배치만 반영한다.
- 선정된 산공과제/비교과로 제한 시범운영하고 공식 청구는 기존 경로에서 1회만 수행한다.

## 이 단계의 특이사항

Notion 읽기 전용 조건을 유지한다. 조회되지 않은 관계나 수식을 0으로 간주하지 않는다. 원본 승인/ERP등록 값만으로 지급 완료를 만들어내지 않는다. 원본·스냅샷·이관 로그는 공개 저장소에 올리지 않는다.

## 산출물

- 공개 가능한 이관 스크립트·가상 매핑 예시
- 비공개 이관 대조표·배치 기록과 공개 가능한 요약
- 시범운영 문제·정책 보완·전환 판정
- 공통: `docs/STATUS.md`, `CHANGELOG.md`, `docs/history/YYYY-MM-DD-phase-09.md` 갱신

## 완료 기준

- M-01~M-03을 시험자료와 승인된 비공개 환경에서 검증한다.
- 원본 변경 0건, 중복 이관 0건, 미대조 금액·파일을 명확히 표시한다.
- 중대 결함이 없고 담당자의 실제 업무 대조 결과가 기록된다.
- 연결 검수: M-01~M-03. [전체 검수표](../06-acceptance.md)에 실제 결과를 연결한다.
- 실패·미실행·미결정을 기록하고 다음 단계 진입 가능 여부를 보고한다.

## 이번 단계 제외

Notion 데이터 정리·상태 수정, 전체 자료 무검증 복사.

## 되돌림·보존

이관 배치별 복원을 준비하고 이후 새 거래가 있는 경우 무조건 삭제하지 않는다. 원본에는 쓰지 않는다.
