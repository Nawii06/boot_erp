# 00단계 — 개발환경·업무 정책 확정

상태: 점검·문서 정리 완료 / 환경 준비·최종 결정 미완료 (2026-10-04). 목표: 사용자의 로컬 PC와 실제 업무 조건을 확인하고 구현의 기준을 고정한다.

## 이번 수행 결과

- [환경 점검·버전 기준안](../environment.md), [역할별 화면·업무 여정](../ui-map.md), [결정 후속 기록](../07-decisions.md), [실행·검수 이력](../history/2026-10-04-phase-00.md)을 작성했다.
- Git·VS Code 설치 파일·Codex 확장 디렉터리·PostgreSQL 바이너리/준비 응답 확인. Node/npm 실행, DB 로그인·전용 DB 권한, IDE 로그인은 미확인 또는 미준비다.
- D-01은 정확한 버전의 기준안까지 정리했으며 최종 채택과 DB 도구 선택은 남았다. D-02~D-13은 담당자·해결 시점을 지정했다.
- 원격 읽기는 가능하나 쓰기 점검은 403으로 실패했다. 로컬 산출물을 보존하고 인증 해결 뒤 푸시해야 한다.
- 문서 산출물 작성과 전체 완료를 구분한다. 01단계 진입은 보류하며 앱 생성·설치·DB 변경·실자료 복사·Notion 접근·외부 연동은 수행하지 않았다.

## 선행조건

문서 기준선와 `../STATUS.md`를 확인한다. `../07-decisions.md`에서 이 단계에 필요한 정책이 결정되었는지 확인한다. 이전 단계의 미해결 중대 결함이 있으면 관련 구현을 먼저 해결한다.

## 개발 범위

- Git·VS Code·Codex 로그인·저장소 쓰기 가능 여부와 현재 변경사항을 확인한다.
- 요구사항 확정/제안/미결정을 구분하고 D-01~D-09를 해당 단계 진입 전에 결정할 수 있게 정리한다.
- 웹 기술·DB·인증·파일 저장 후보를 비교하여 선택 이유·정확한 버전·환경을 기록한다.
- 실제 사전품의/청구 서식과 비목·세목 체계의 제공 여부를 확인한다. 미제공 자료의 내용을 추정하지 않는다.
- 역할별 화면 목록과 한 건의 대표 업무 여정을 합의 가능한 초안으로 작성한다.

## 이 단계의 특이사항

Google SSO, 자체 Windows 서버, 특정 라이브러리는 이번 대화에서 확정되지 않았다. 사용자 PC의 설치 상태를 이 환경에서 확인한 것으로 쓰지 않는다. 기존 Notion은 읽기 전용이며 새로 수정·연동할 이유가 없다.

## 산출물

- docs/environment.md: 로컬 환경·선택 기술·실제 점검 결과
- docs/ui-map.md: 역할별 화면·작업 동선
- 공통: `docs/STATUS.md`, `CHANGELOG.md`, `docs/history/YYYY-MM-DD-phase-00.md` 갱신

## 완료 기준

- 다음 01단계에 필요한 기술·버전·개발 DB·실행 환경이 결정되어 있는지 확인한다.
- 권한·금액 정책의 미결정은 임의 승인 처리하지 않고 담당 단계와 해결 시점을 명시한다.
- 앱 전체 생성·운영자료 복사·Notion 변경을 수행하지 않았는지 확인한다.
- 연결 검수: 문서·환경 확인. [전체 검수표](../06-acceptance.md)에 실제 결과를 연결한다.
- 실패·미실행·미결정을 기록하고 다음 단계 진입 가능 여부를 보고한다.

## 이번 단계 제외

앱 기능 일괄 구현, 운영 서버 배포, 실자료 이관.

## 되돌림·보존

문서 변경을 Git diff로 확인하고 필요하면 해당 문서 커밋을 되돌린다. 사용자 로컬 설정은 기록 없이 바꾸지 않는다.
