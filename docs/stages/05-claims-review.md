# 05단계 — 사후 청구·검토·보완

상태: 미착수 / 목표: 사전신청을 이어 받아 실제 사용내역을 청구하고 검토확정한다.

## 선행조건

04단계 완료 증거와 `../STATUS.md`를 확인한다. `../07-decisions.md`에서 이 단계에 필요한 정책이 결정되었는지 확인한다. 이전 단계의 미해결 중대 결함이 있으면 관련 구현을 먼저 해결한다.

## 개발 범위

- 사전신청에서 청구 이어쓰기와 별도 공식 근거가 있는 청구 등록 경로를 만든다.
- 청구 표지·세부행·요청금액·증빙·사용일·지급대상 등 입력과 제출본 버전을 구현한다.
- 담당자의 서류별 보완, 연구원의 재제출, 검토확정액과 조정사유를 구현한다.
- 같은 집행 건의 기존 예약을 조정하며 최종/추가 청구 구분을 반영한다.
- 담당자 입력대행·연구원 인수인계가 필요하면 실제 행위자와 대상자를 기록한다.

## 이 단계의 특이사항

사전 승인 금액과 실제 청구액은 다를 수 있다. 예약을 새로 더하거나 일부 청구 후 전체 예약을 해제하지 않는다. 상신된 제출본을 덮어쓰지 않는다. D-08의 청구·배분 범위가 선행되어야 한다.

## 산출물

- 청구 작성·검토대기·보완·확정 화면
- 제출본·검토의견·금액조정·예약 전환 기록
- 연구원/담당자 왕복 업무 검수
- 공통: `docs/STATUS.md`, `CHANGELOG.md`, `docs/history/YYYY-MM-DD-phase-05.md` 갱신

## 완료 기준

- W-03~W-05, F-03 및 관련 권한 검수를 수행한다.
- 확정 후 연구원의 직접 수정과 권한 밖 첨부 교체를 차단한다.
- 여러 지출행 합계와 요청/확정금액이 일치한다.
- 연결 검수: W-03~W-05, F-03. [전체 검수표](../06-acceptance.md)에 실제 결과를 연결한다.
- 실패·미실행·미결정을 기록하고 다음 단계 진입 가능 여부를 보고한다.
