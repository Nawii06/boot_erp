# 03단계 예산 사용·인수인계

03단계는 예산배정·변경 화면과 신청 차감/복원 공통 서비스를 제공한다. 지출 신청 전체 화면·증빙 제출·실청구·지급 입력은 후속 단계다. 실제 예산 원문과 금액은 아직 DB에 이관하지 않았다.

## 화면에서 사용하는 순서

1. 기존 Google 계정으로 로그인하고 **예산배정·변경** 메뉴를 연다.
2. 담당자 또는 관리자가 **분류코드 관리**에서 비목 → 세목 → 세세목 순서로 등록한다. 실제 입력 시에는 비공개 확정표의 코드·부모 관계를 그대로 사용한다. 가상 시험에는 별도 가상 코드를 사용한다.
3. 담당자가 과제·비교과를 선택하고 **예산 최초 배정**에서 항목명·재원·세세목·원 단위 금액·사유를 입력한다. 현재는 2026학년도 과제에 확정된 공통 기간을 적용한다. 최초 배정은 총액 설정이므로 담당자만 수행한다.
4. 연구원·담당자·관리자는 **예산변경 신청**에서 변경 후 금액·사유·근거 첨부를 입력한다. 연구원·관리자의 변경신청은 같은 과제 안에서 증감 합계가 0원이어야 한다. 총액 증감 신청은 담당자만 가능하다.
5. 담당자 또는 관리자가 신청 상세를 열고 **검토 시작 → 최종 확정**을 진행한다. 조회만으로 검토가 시작되지는 않는다. 담당자 신청의 총액 증감도 관리자가 최종 확정을 대행할 수 있다.
6. 확정 시점에 다른 신청·예산변경이 발생했으면 충돌 안내가 표시된다. 새로고침하여 잔액을 확인하고 반려·취소 후 새 변경신청을 제출한다. 새 신청에서 이전 건을 선택하면 기존 첨부·내용을 보존하면서 연결한다.

확정 건은 취소 버튼으로 덮어쓰지 않는다. 정정이 필요하면 현재 금액·버전 기준의 새 예산변경을 사유와 함께 신청한다. 연구원은 본인 변경신청·첨부만 조회하며 책임자는 담당 과제 전체를 조회한다. 공통 예산항목·잔액 조회는 동료의 개별 지출·첨부 열람 권한을 의미하지 않는다.

## 금액과 첨부

- 최초예산은 불변이며 현재예산은 확정된 변경을 반영한다. 사용 가능 잔액 = 현재예산 - 유효 신청 차감액이다.
- 신청 차감·복원 서비스는 동일 신청 건과 업무 배정에 연결한다. 보완은 차감 유지, 금액 수정은 복원 후 수정·재신청, 승인 후 취소는 지급 전 담당자·관리자만 허용한다.
- 실제 지급 입력 API는 아직 없다. 지급 발생 건 취소 차단은 시험 DB의 가상 지급 상태로 검증하며 실제 지급 기능 완료로 해석하지 않는다.
- 첨부는 최대 5MiB, PDF·PNG·JPEG·HWP·HWPX·DOC·DOCX·XLS·XLSX를 지원한다. 확장자·선두 서명·크기 검사를 하며 파일 내부를 추출하거나 실행하지 않는다. 실제 공식 양식과의 호환성은 실파일 수령 후 별도 확인한다.
- 파일은 PostgreSQL 비공개 bytea로 저장한다. 변경신청·첨부·감사를 한 트랜잭션으로 저장하고 다운로드마다 현재 세션·배정을 검사한다. 공개 저장 경로가 없으며 브라우저 표시 대신 다운로드한다.
- 문서 컨테이너 내부 검증·악성코드 검사는 이번에 구현하지 않았다. 운영 파일량·보존·검역·DB와 파일 복구는 08~10단계 운영 준비에서 검토한다.

## 개발·검수

```powershell
.\scripts\app.cmd run local -- migrate
.\scripts\app.cmd run local -- migrate:test
.\scripts\app.cmd test
.\scripts\app.cmd run local -- test:db
.\scripts\app.cmd run typecheck
$env:NEXT_TELEMETRY_DISABLED='1'
.\scripts\app.cmd run build
.\scripts\app.cmd run local -- test:ui
.\scripts\app.cmd run check:docs
```

`test:db`와 `test:ui`는 전용 시험 DB의 임시 스키마에서 가상 자료만 사용하고 종료 시 정리한다. `test:ui`는 포트 3000이 비어 있어야 하며 기존 서버를 자동 종료하지 않는다. 마이그레이션은 기존 예산 원금·계정·업무를 보존하며 새 테이블을 추가한다. 기존 01단계 가상 예산행을 실제 사용 가능 잔액으로 자동 전환하지 않는다.

이후 서버 실행은 [기존 비공개 Google 설정 안내](google-login-setup.md)를 따른다. 비공개 원본을 seed나 공개 테스트에 복사하지 않는다.
