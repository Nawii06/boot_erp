# 04 진입 준비 재점검

점검일: 2026-10-20 / Asia/Seoul. 요청: 사전 준비를 점검하고 준비가 완료됐다면 04단계를 진행.

## 판정

**공통 기반·운영 기준은 준비됐으나 04 전체 준비 완료 조건은 미충족이다.** EX-07의 B 상세 규칙 적용 보류, EX-11의 기준 미확인 시 제출·최종 승인 처리 미결정이 남았다. 조건부 진행 지시를 보류 해제나 정책 승인으로 확대하지 않는다.

단가·한도 실제 수치는 차후 설정 가능하므로 값 미입력 자체는 공통 기반 개발을 막지 않는다. 다만 미확인 상태의 제출·승인, 규칙 적용 기준일·초과 처리의 동작을 구현하려면 기대 결과가 정해져야 한다. 연구인력 범위 미결정은 해당 유형의 상세 규칙에 영향을 주며 모든 공통 기능을 막는 항목은 아니다.

## 진행 선택지

1. 전체 04: B 적용 보류 해제/최종 기준과 기준 미확인 상태의 제출·승인 처리를 결정한 뒤 진행한다. 이미 확정된 A·권한·제출 시점은 다시 묻지 않는다.
2. 제한 범위: B 보류를 유지하면서 확정된 공통 초안·비공개 첨부 기반·설정 관리를 먼저 구현하고 제출·승인 활성화를 제외할 수 있다. 사용자가 이 범위를 지정하면 진행하며 04 전체 완료로 표시하지 않는다. 기존 `budget-spend` 경로까지 포함해 미구현 정책의 우회가 없도록 설계해야 한다.

이번에는 두 번째 선택지를 자동으로 채택하거나 앱·DB를 변경하지 않았다. 구현 브랜치 생성·마이그레이션·실자료 이관·Notion 접근·main 병합·운영 배포는 하지 않았다. 정책 변경이 없어 결정기록은 수정하지 않았다.
