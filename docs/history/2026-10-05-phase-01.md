## 실패·수정·미실행

- 최초 DB 검수에서 교차 DB URL을 문자열 replace하여 DB명 대신 사용자명을 바꿨다. 예상 권한 오류 42501 대신 인증 오류 28P01로 1개 하위 검수가 실패했다. URL의 pathname만 바꾸도록 수정한 뒤 하위 9개 모두 통과했다. 최초 실패를 성공으로 바꾸어 기록하지 않는다.
- Next 개발 서버가 AGENTS.md에 자체 지침 블록을 자동 추가했다. 설치본 공식 안내를 확인한 뒤 `agentRules: false`를 설정하고 자동 추가 블록을 제거했다. 기존 저장소 작업 원칙은 보존하고 오래된 “설계 문서 단계” 문구만 STATUS 참조로 갱신했다.
- 내장 브라우저가 없어 화면 검수는 연결된 Edge로 수행했다. 모바일 화면·전체 접근성 자동검수는 미실행이다.
- 다른 PC 전체 설치, 실제 로그인·계정관리, 실제 업무 권한 인수검수, 예산 예약/중복 지급, 파일 검역/업로드, 운영 배포/백업복구는 미실행이다. 이번 단계 범위 밖이며 해당 단계에서 검수한다.
- D-02~D-13은 새 사용자 답변 없이 확정하지 않았다. Notion 접근/변경·홈페이지/대학 ERP 외부 연동·실자료 이관 없음.
