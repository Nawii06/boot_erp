# 04 추천안 보류·후속 답변 기록

작업일: 2026-10-20 / Asia/Seoul.

## 요청과 해석

사용자는 B-01~B-09에 “추천안 채택하고자 하니, 적용 전 기록만 남겨놓고 차후 결정”이라고 답했다. 최종 채택이나 구현 지시로 확대하지 않고 의향 기록·적용 보류로 남겼다.

- 연구인력지원비 실제 범위: 확인 필요 유지.
- 외부전문기술활용비: 전문가 자문 및 업체 기술지원 등을 포함. 명시되지 않은 기타 범위는 임의 확대하지 않는다.
- 제출 시점: 추천 채택. 유형별 필수서류 목록의 보류와 공통 시점의 채택을 구분했다.
- 설정 탭 구성·관리 권한: 추천 채택. 실제 수치·적용 기준일·초과 처리는 미결정이다.
- 기준 미확인 시: 초안 허용만 확정. 초안은 신청 제출 전이므로 차감하지 않는다. 제출·최종 승인 허용/차단은 미결정이다.

필수 증빙이 누락된 경우의 기존 승인 차단은 유지한다. 이를 단가·한도 등의 기준 자체가 미확인인 경우의 최종 승인 차단과 혼동하지 않는다.

## 변경 범위와 검수

준비표·요구사항·결정 EX-07~EX-11·진행상황·04 계획·연혁을 문서로 반영했다. 기존 작업 트리는 깨끗했으며 원문 추천표는 보존했다. 현재 답변을 다시 요구하지 않고 차후 결정용 양식으로 바꿨다.

- `scripts/app.cmd run check:docs`: Markdown 62개·상대 링크 312개·누락 대상 0개로 통과.
- `git -c core.safecrlf=false diff --check`: 통과. 확정·보류·미결정 표시와 단계 상태를 대조했다.
- 문서만 변경하여 앱 테스트·타입 검사·빌드는 재실행하지 않았다. 앱·DB·설정값·Notion·실자료·main·배포는 변경하지 않았다.
- 커밋 대상은 공개 가능한 정책·제안·이력 문서이며 실제 개인정보·내부 원문·인증정보는 추가하지 않았다. 커밋·푸시 SHA는 최종 보고에 기록한다.

남은 사항: B 최종 결정, 연구인력지원 범위, 실제 기준값과 적용 기준일, 미확인 상태의 제출/승인·초과 처리. 03 완료·04 기능 미착수 상태를 유지한다.
