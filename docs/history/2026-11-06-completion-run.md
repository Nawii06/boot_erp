## 최종 UI·금액 대조

1600×1000/1280×800/375×812에서 네 역할×주요8화면과 담당자/관리자 계정·보안 화면의 **108개 조합**을 실제 탐색하고 제목/역할 메뉴/페이지 폭을 확인했다. 작은 화면의 신규 신청 폼·증빙 있는 신청 첨부/제출 이력·지급 상세·확장 지급/환입 폼도 확인했다. 동료 격리·키보드·접는 메뉴·표 내부 스크롤·미저장 이동 취소·실패 입력 보존을 검수했고, 예산 과제 변경을 취소하면 선택값과 미저장 입력을 보존했다. [데스크톱](../qa/dashboard-synthetic-2026-11-06.png), [모바일](../qa/dashboard-mobile-synthetic-2026-11-06.png)은 **격리 가상 서버를 실제 렌더링한 PNG**다. 본문 바로가기는 키보드 포커스 때 표시된다.

가상 fixture 현재예산100,000,000/차감40,000,000/가용60,000,000/지급25,000,000을 실제 서비스로 구성했다. UI에서 신규200원 신청→보완→재제출→승인→실청구→지급200→환입50+복원→마감/재개방을 수행한 뒤 차감40,000,150, 지급25,000,200, 환입50, 순집행25,000,150을 DB·대시보드와 대조했다. 시험 스키마·세션·서버를 정리했으며 가상 기준/거래를 dev/test public에 남기지 않았다.

컨셉과 같은 주요 구획·순서·색·폭을 확인했다. 실제 기능이 없는 종 아이콘을 추가하지 않았고, 실제 열린 탭만 표시했다. 예산·건수·행수는 가상 DB의 실제 값이며 이미지의 3/2/1건을 하드코딩하지 않았다. 날짜/권한/집계 설명과 기존 초안 메뉴 때문에 내용 높이는 늘어날 수 있다.

## 실패·수정과 증거 재사용

- 최초 빌드: PowerShell을 거친 한글 테스트 문자열 손상과 P6 타입/fixture 동시 편집 중 오류로 실패. 한글을 정상 복원하고 타입 계약을 맞춘 뒤 빌드/타입 통과했다.
- 모바일: 숨김 label의1px 폭을 모바일 공통100% 규칙이 덮어 페이지가28px 넘쳤다. 숨김 label을 공통 폭 규칙에서 제외한 뒤3뷰포트 재통과했다.
- 신규 UI: select label에 option 문구가 합쳐져 접근성 이름이 바뀌었다. 명시적 aria-label로 고친 빌드에서 전체 여정 통과했다.
- 확대 행렬: 375px 사용자 메뉴가 x=-131px로 잘리는 결함을 실제 bbox로 확인했다. 모바일 팝오버를 화면 안 고정 위치로 수정하고 담당자/관리자 메뉴 bbox·추가 본인 확인 실제 클릭 및108개 조합을 재검사해 통과했다. 예산/계정/업무 내부 이동의 미저장 보호도 보강했다.
- 기존 UI: 접는 모바일 메뉴와 바뀐 안내에 과거 검수 절차가 맞지 않아 실패했다. 메뉴 열기를 반영하고, 계정 교체 중 일시적인 로딩 상태를 새 연구원 역할 표시까지 기다린 뒤 검사해 통과했다. 인증/격리 assertions를 제거하지 않았다.
- 감사·검토의견 시간 역전, 세부 사용기간 누락, KST SQL DATE 전날 변환은 [코드 감사](../qa/completion-code-review-2026-11-06.md)의 재현/수정/회귀로 해소했다. 지급 상세·예산/분류 날짜도 문자열로 유지하고 당일 분류 적용을 KST로 비교했다.
- 초기 입력검사 EPERM/캐시 오류, 백업 ACL 오류, SQL 카탈로그 assertion 오류·DATE 별칭 ORDER BY 충돌도 담당 기록의 실패로 보존했다. 최종 통과로 초기 실패를 지우지 않았다.
- 공개 파일 대조 최초 명령은 rg 패턴 옵션과 절대/상대 경로 처리 오류로 완결되지 않았다. 옵션·경로 구분과 오류 중단을 보정한 뒤 최종 패턴/실제 비밀값 대조를 완료했다. 오류가 있던 출력의 발견0을 통과 증거로 사용하지 않았다.
- UI 변경과 무관한 도구/DB 검사는 재사용했다. 날짜·감사·기간 변경 후 관련 DB 및 최종82건을 재검사했다. 기존 브라우저 회귀의 인증·계정·예산·파일 결과를 재사용하고, 이후 내부 이동/모바일 CSS 영향은 최종 빌드의108화면 조합·미저장 보호·신규 여정/HTTP로 재검사했다. 문서만 추가한 뒤 앱 회귀 전체를 다시 반복하지 않았다.

## G1 판정과 후속 경계

**G1 미완료**다. 독립 업무 구현과 가상 로컬 검수는 끝났으나 실제 Google 인증/원래 키 복구, 운영 대상·접속/TLS·운영자·자료/동시사용 규모·보존/검역·백업 위치/주기·RPO/RTO 및 해당 실환경 성능/복구/롤백 검증이 남아 있다. 로컬 복원을 운영 키 복구로 확대하거나 미실행 필수를 선택으로 낮추지 않았다. 사소한 여백/아이콘 다듬기는 선택 보류다.

P8 실제 입력·P9 Notion 연계는 시작하지 않았다. G1 해소 후 실제 기준값/연구인력 범위, 원본·입력 대상·기준일·대조 책임·수기/배치·기초잔액 방식을 확정하고 비공개 백업/dry run/대조를 준비해야 한다. 원본 Notion은 그대로 읽기 전용이다.
