# 04 기본 운영 답변 반영·유형별 추천안

작업일: 2026-10-20 / Asia/Seoul.

## 요청과 변경

사용자는 초기 지출 유형 9종을 지정하고 A-02~A-08 추천안을 채택했다. A-09는 확인 필요로 두고 차후 유형별 단가·한도 설정 탭을 요청했으며, A-10은 기존 자료가 현재 적용본임을 확인했다. B는 A-01을 기준으로 추천안을 정리·제안하라고 요청했다.

- 준비표의 A 재질문을 종료하고 확정값으로 교체했다. 결정 EX-01~EX-06과 요구사항 R-16/R-37~R-41을 반영했다.
- B-01~B-09에 입력·신청 시 자료·승인 전 자료·조건부 확인을 제안했다. 번호는 답변용이며 기존 예산 분류 코드와 무관하다.
- 지급 전 신청에는 청구/산출 자료로 확인하는 방안을 제안하여 내부 승인을 실제 지급과 혼동하지 않게 했다.
- 단가·한도 설정 탭은 요구만 확정하고 세부 권한·버전·미확인/초과 처리·기한 확장은 제안으로 구분했다.
- 현재 적용본은 사용자 확인 근거다. 이번에 비공개 원문·Notion을 다시 조회하거나 법령·세무 적정성을 검증하지 않았다. 실제 단가·한도·기한을 만들지 않았다.

03 완료 상태를 유지한다. 04는 기본 정책 확정·B 검토 대기이며 기능 미착수다. 앱·DB·운영자료·main·배포는 변경하지 않았다. 기존 작업 트리는 깨끗한 상태에서 시작했다.

## 검수와 남은 사항

- `scripts/app.cmd run check:docs`: Markdown 61개·상대 링크 306개·누락 대상 0개로 통과.
- `git -c core.safecrlf=false diff --check`: 통과. 확정/추천/미결정 및 03 완료·04 미착수 상태를 대조했다.
- 문서만 변경하여 앱 테스트·타입 검사·빌드는 재실행하지 않았다. 이번 결과를 앱 검수 통과로 표시하지 않는다.
- 커밋 대상은 정책·제안·작업기록 문서뿐이며 실제 개인정보·증빙 원문·단가·인증정보를 추가하지 않았다. 작업 브랜치의 커밋·푸시 SHA는 최종 보고에 기록한다.

남은 사항은 B 추천안 채택/수정, 연구인력지원비와 외부전문기술활용비의 실제 범위, 조건부 증빙·단가·기한·설정 탭의 상세 동작이다. 미확인 값을 제한 없음으로 취급하지 않는다. 사용자 현재 적용본 확인은 반복 요청하지 않는다.
