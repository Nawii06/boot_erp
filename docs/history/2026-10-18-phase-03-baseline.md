# 03 준비 입력 완료 — Notion 기준·사용기간

기록일: 2026-10-18. 사용자가 PDF보다 Notion을 모두 우선 적용하고 사업연차·사용기간·등록 기준 분류를 확정했다. 이번 범위는 정책·문서·비공개 로컬 코드표 구성이다.

## 확정 내용

- 사업명: 1차년도 부트캠프 사업.
- 사업연차: 1차년도(2026학년도).
- 사용기간: 2026-03-01~2026-12-31, 모든 산공과제·비교과 동일.
- 금액·배정·분류는 Notion 등록값을 기준으로 한다. 기존 PDF 분류에 억지로 맞추지 않는다.
- 입력 기준액은 Notion 배정액이며 과거 변경요청 차액을 중복 가산하지 않는다. 배정액을 가용잔액이나 실제 지급액으로 간주하지 않는다.

BC-11~BC-13 및 R-35/R-36을 추가했다. 이전의 PDF/Notion 기준 범위·기간·세세목 연결 확인 대기는 이번 답변으로 종료한다. 과거 이력은 보존한다.

## 로컬 자료 갱신

기존에 확인한 Notion 스키마에 따라 예산배정의 필요한 열만 읽기 전용으로 재조회했다. 73행·`has_more=false`이며 이전 조회 대비 이름·관계·분류·금액 변경은 없었다. 프로젝트 목록은 이전에 확인한 자료를 재사용했으며 이번에 프로젝트 DB 전체를 재조회한 것으로 기록하지 않는다. Notion 쓰기 도구는 호출하지 않았다.

등록 세목 9종을 명시적 대응표로 상위 분류에 연결하고 그 아래 구분 원문을 세세목으로 사용했다. 비목 7개·세목 9개·세세목 25개로 구성한 것은 ERP 표시 구조이며 Notion에 별도 비목 필드가 존재한다는 주장은 아니다. 복합 세목과 유사 명칭·공백·묶음 용도는 임의 정규화·분할·통합하지 않았다. 예산항목 제목은 프로젝트별 배정명으로 보존한다.

기존 PDF의 B 코드와 구분하여 N 코드 계열을 부여했다. 기관 공식 코드로 표현하지 않으며 이미 발급한 코드 의미를 덮어쓰지 않는다. 과거 PDF 표·이전 매핑 후보 검토표는 별도 이력으로 보존하고 사용자가 열어 둔 로컬 검토표를 현행 기준표로 갱신했다. 구조화된 기준 JSON도 작성했다.

실제 이름·금액·원문 URL·코드 대응표는 Git 제외 로컬 참고 폴더에만 보관한다. 공개 문서에는 정책·형식·검수 결과를 기록한다. 원문 이동·삭제, 실예산 DB 입력, 앱 변경·마이그레이션, main 병합·운영 배포는 수행하지 않았다.

## 검수·다음 작업

로컬 코드표의 코드 중복·부모 관계·73행 전체 매핑·프로젝트별 합계·원 단위 정수·원문 명칭/금액 보존·공통 기간 검사를 통과했다. `scripts/app.cmd run check:docs`는 로컬 Markdown 55개(비공개 참고표·이력 3개 포함)·상대 링크 253개 누락 없음, `git diff --check`는 공백 오류 없음이다. `git ls-files custom_ref` 결과는 비어 있고 현행표·JSON·로컬 작성 스크립트는 Git 제외 상태다. 문서 작업이므로 앱 테스트는 실행하지 않았다.

03 준비 입력은 완료됐다. 다음은 예산배정·변경 신청·필수 비공개 첨부·신청 차감/복원 공통 기능 구현과 가상 검수다. 실사용 자료 입력·기존 사용내역 이관은 별도 단계이며 지급 후 정정·분할 등 후속 정책을 이번 확정으로 확대하지 않는다.
