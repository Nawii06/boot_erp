# 02단계 인증 앱 등록 만료 안내 개선

작업일: 2026-10-18 (Asia/Seoul). 범위: 02 실제 로그인 검수 중 발견된 등록 오류 안내 개선.

## 원인과 확인 근거

사용자는 ERP의 **인증 앱 등록 키 보기**에서 일반 권한 오류를 보고했다. 비공개 개발 DB를 값 노출 없이 조회한 결과 관리자·활성 상태는 정상, 유효 세션은 1개, Google 로그인 후 5분 이내 세션은 0개였다. 인증 앱 등록 시작·확인 완료 기록은 없었다.

서버는 최초 등록과 최초 코드 확인에 최근 5분 이내 Google 로그인을 요구하지만, 만료를 일반 `FORBIDDEN`으로 반환해 화면에서 원인을 구분하지 못했다. 권한 부여 누락이 아니라 최초 등록 시간 만료다.

## 변경 내용

- 해당 만료를 `REAUTH_REQUIRED`(HTTP 403)로 구분하고 한국어 사유와 **Google로 다시 로그인** 버튼을 제공한다.
- 기존 Google 로그인 흐름을 재사용해 새 세션을 발급한다. 서버의 5분 검사·역할 검사·TOTP 검증은 유지한다.
- 정상 등록·확인 후 만료 안내를 해제한다. 새로고침이나 유휴 시간 연장으로 최초 등록 제한을 우회하지 않는다.
- 사용 안내·진행상황·단계 체크리스트·연혁을 갱신했다. 정책 변경은 없어 결정기록의 기존 정책을 유지한다.

## 실행 검수

| 명령·확인 | 결과 |
|---|---|
| `scripts/app.cmd run local -- test:db` | 28/28 통과(부모 2개 포함). 유효 세션이라도 최초 등록 5분 만료 시 거부, 새 세션에서 등록 가능, 등록 도중 만료 시 확인 거부·미확정 유지 |
| `scripts/app.cmd test` | 단위 8/8 통과 |
| `scripts/app.cmd run typecheck`, `scripts/app.cmd run build` | 통과 |
| `scripts/app.cmd run local -- test:ui` | 격리된 가상 계정으로 만료 안내·재로그인 버튼 표시와 정상 등록 키·코드 확인·DB 확정 기록 검수. 기존 역할·폼·세션·모바일 검수 통과 |
| `scripts/app.cmd run test:http` | 수정 앱 재실행 후 홈·DB 상태·인증 없는 요청 차단·파일 경로 미개방 통과 |
| `scripts/app.cmd run check:docs`, `git diff --check` | Markdown 47개·상대 링크 200개 누락 없음, 공백 오류 없음 |

브라우저 검수의 시간 조정과 TOTP 생성은 격리된 가상 자료에만 수행했다. 실제 Google 재로그인 버튼의 외부 왕복과 실제 인증 앱 입력은 사용자의 재시험이 필요하다. 실제 계정의 등록 키·코드·세션 토큰은 읽거나 대신 입력하지 않았다.

## 남은 작업과 인수인계

사용자 시험용 localhost:3000 앱과 개발 DB를 실행해 두었다. 화면 새로고침 후 등록 만료가 표시되면 **Google로 다시 로그인**하고, 5분 이내에 **추가 본인 확인 → 인증 앱 등록 키 보기 → 코드 확인**을 마친다. 로그아웃 후 Google 로그인으로 다시 시작해도 된다.

실제 ERP 인증 앱 등록 성공 보고와 DB의 확인 완료 기록을 대조한 뒤 02 종료를 판정한다. 현재는 재시험 대기다. 03 구현·main 병합·운영 배포·Notion 변경은 수행하지 않았다.
