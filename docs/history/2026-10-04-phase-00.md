## 결정과 남은 사항

- 확정 요구는 C-01~C-09 유지. 정확한 버전 후보를 작성했으나 D-01 최종 채택·DB 도구 선택·실행 준비는 미완료다.
- 기관 로그인/서버·망 제한, 공동 참여자 열람 범위, 공식 서식/분류체계 제공 여부를 묶어 문의했다. 답변 없는 사항은 미결정으로 남겼다.
- 공식 서식·비목·세목 원본은 현재 저장소에 없다. 기존 자료목록의 과거 검토만 참조했고 원본의 최신성·완전성을 확인했다고 쓰지 않았다.
- Node/npm 실행 경로, 프로젝트 전용 DB와 제한된 역할, IDE 로그인 및 GitHub 쓰기 권한이 남았다. 00단계 전체 완료 및 01단계 진입은 보류한다.
