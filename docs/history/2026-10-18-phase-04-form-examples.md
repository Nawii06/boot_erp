# 04 사전 준비 양식 — 추천안·예시 보완

작업일: 2026-10-18. 사용자가 추천안 또는 예시를 포함한 준비표·답변 양식을 다시 요청했다. 기존 양식을 보완했으며 새 업무 정책을 승인한 요청으로 해석하지 않았다.

## 변경 내용

- A-01~A-10에 선택할 운영 기준·추천안·이유와 영향을 정리했다. 과제 전체 예산변경과 지출 신청 항목 선택 권한을 구분했다.
- 공통 입력, 유형별 증빙 제출 시점, 서식 파일 활용, 파일당/건별 용량과 개수, ZIP 미지원 출발안을 제안으로 표시했다.
- 회의비·출장비·재료/소모품 구입비의 입력·서류 이름 후보를 가상 예시로 작성했다. 기관 필수 증빙·단가·기한으로 확인된 목록이라고 표시하지 않았다.
- 항목 번호로 추천안 채택·수정·확인 필요를 답할 수 있도록 했다. 근거·적용일·기존 자료 최신성은 추천안 일괄 채택만으로 검증 완료 처리하지 않는다.

기존 확정 정책과 03 완료 상태는 유지한다. 04는 업무별 답변 대기·기능 미착수다. 앱·DB·Notion·실자료·main·배포는 변경하지 않았다. 결정기록에는 미승인 제안을 확정값으로 추가하지 않았다.

## 검수

- `scripts/app.cmd run check:docs`: Markdown 60개, 상대 링크 294개, 누락 대상 0개로 통과했다.
- `git -c core.safecrlf=false diff --check`: 통과했다. 확정/제안/예시 구분과 상태 일관성을 확인했다.
- 문서만 변경하여 앱 테스트는 재실행하지 않았다. 이번 결과를 앱 검수 결과로 표시하지 않는다.
- 남은 사항: 유형별 실제 필수서류·단가·기한·기존 자료 최신성은 사용자 답변과 근거 대조가 필요하다. 커밋·원격 반영 결과 SHA는 작업 보고에 남긴다.
