## 사용자 지시와 결정

사용자가 기존 세션·복구 권고안을 사용하도록 승인했고, 사전 등록 이메일만 로그인·관리자 계정 관리는 관리자만·다른 이메일의 Google 계정 허용 및 담당자 수기 소유 확인을 지시했다.

- AC-08: S-01~S-10 확정. 유휴 15분·최대 8시간·만료 2분 전 경고·동시 2세션, 장기 로그인 미제공, 현재/전체 로그아웃, 보안 변경 시 세션 폐기, 민감 작업 전 최근 5분 추가 본인 확인, Google/ERP 복구 절차 구분.
- AC-09: 사전 등록 이메일만 로그인 허용.
- AC-10: 관리자 계정 관리와 관리자 역할 부여·회수는 관리자만 수행.
- AC-11: 다른 이메일로 만든 Google 계정 허용. 담당자가 소유를 수기로 확인. 일반 계정의 관리자 대행은 기존 결정을 유지하고 관리자 계정은 AC-10을 우선 적용.

AC-07 및 이전 작업기록의 미결정 표시는 당시 이력으로 보존한다. 현재 정책 문서·요구사항·권한표·STATUS·02 작업서·화면·예정 검수·AGENTS·연혁을 최신 결정으로 맞췄다.

## 구현 방침과 적용 범위

수기 확인은 사전 등록과 별도 상태로 관리하고 대상 계정/이메일·확인자·시각·방법·결과를 비공개 감사기록에 남긴다. 확인 대기/실패 시 세션 발급을 차단하고 이메일 변경·인증 연결 복구 시 재확인한다. 수기 확인이 유효한 Google 인증·활성 계정 검사를 대체하지 않는다. 확인 기록을 정정할 때 원 기록을 보존한다.

정책 확정과 문서 갱신만 수행했다. 코드·DB·라이브러리·Google OAuth 자격증명은 변경하지 않았다. Notion·메일·홈페이지·대학 ERP 업무자료 연동, 실제 소유 확인, 운영 배포, main 병합은 수행하지 않았다. 공개 문서에는 실제 이메일·확인 증빙·인증정보를 추가하지 않았다.
