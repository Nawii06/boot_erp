## 02 실행 순서와 종료 조건

1. 불변 계정 ID를 유지하며 인증 제공자·이메일·수기 확인·세션·계정 감사 모델을 확장한다. 기존 감사 모델의 필수 프로젝트 참조를 계정 관리 감사에 어떻게 적용할지도 설계한다.
2. Google OAuth 비공개 실행 설정과 추가 본인 확인 수단을 검증하고 로그인·세션·복구를 구현한다. 설정 없이 진행한 가상 제공자 검수는 실제 Google 연결 검수와 구분한다.
3. 일반 계정은 담당자 우선·관리자 대행, 관리자 계정은 관리자만 관리하게 한다. 미등록·수기 미확인·정지 계정 차단을 구현한다.
4. 과제/비교과·참여자·업무 배정·인수인계를 화면/API로 구현하고 연구원 업무 격리와 책임자 담당 범위 조회를 적용한다.
5. A-01~A-12를 실제 서버 요청으로 검수하고 결과·실패·미실행·남은 위험을 기록한다. 이후 업무 단계의 파일·청구·지급·출력 경로도 구현 시 같은 정책으로 별도 검수한다.

02 종료는 정책 문서 작성이 아니라 기능 구현·검수·인수인계까지다. Google 자격증명이 미준비여도 독립적인 설계·가상 검수는 가능하지만, 실제 연결을 미검수로 남긴 상태를 전체 완료로 기록하지 않는다.
