# 03단계 예산 정책·분류 준비

날짜: 2026-10-18. 근거: 사용자의 D-02/D-03/D-07 답변과 제공 PDF의 수정 후 예산표. 이번 범위는 정책 반영·분류코드 구성·문서 검수이며 기능 구현이 아니다.

## 확정·변경

- 신청 즉시 가용액 차감, 신청 전 복귀 시 차감 취소·복원으로 기존 내부검토 완료 예약 추천안을 대체했다. 사전 예산·사후 청구 분리를 제거하고 금액·업무 설계를 갱신했다. 차감 효력 삭제와 감사이력 삭제를 구분한다.
- 연구원은 담당 과제 전체 항목 간 예산변경 신청 가능. 과제 간 이동·총액 증감 불가, 총액 증감 담당자만. 담당자 검토·확정 및 관리자 확정 대행. 사유·전후 금액·첨부 필수, 기존 차감·지급을 침해하는 감액 차단.
- 내부 승인에 외부 공식 승인 여부 관리를 요구하지 않는다. 실제 지급과 내부 승인은 구분한다.
- 비목·세목·세세목 공통 분류, 담당자·관리자 변경·승인, ERP 내부 관리코드 구성. 사용자 원문을 기관 공식 코드·법정 단가 확인으로 확대하지 않는다.
- AGENTS·요구사항·결정기록·권한표·금액 설계·03 단계·예정 검수·진행상황·연혁을 동기화했다. 04/05·화면 흐름의 종전 초안은 현행 정책으로 대체됨을 표시하고 상세 재설계를 다음 작업으로 남겼다.

## 원문 검토·보호

PDF 2쪽 중 예산이 있는 1쪽 전체를 텍스트 추출하고 이미지로 렌더링하여 수정 전/후 및 병합 셀을 대조했다. 2쪽에는 예산표가 없다. 수정 후 기준 비목 2개·세목 8개·세세목 14개를 구성하고 원문 행별·세목별·비목별·전체 합계를 대조했다. 묶음 행의 금액은 분할하지 않았으며 과제 수를 다시 곱하거나 각 과제에 균등 배분하지 않았다.

원문과 실제 금액·매핑표·JSON은 공개 커밋에서 제외했다. 사용자가 제공한 로컬 참고 폴더를 `.gitignore`에 추가했고 원문은 이동·삭제하지 않았다. 해당 폴더의 추적 파일은 없었다. 저장소 밖 영구 비공개 보관 위치는 별도 운영 항목이다. 공개 문서에는 정책·코드 형식·검토 결과와 가상 예만 기록한다.

PDF 도구는 임시 uv 환경의 PyMuPDF로 준비했다. 앱 의존성·lockfile은 변경하지 않았다. 렌더 이미지는 OS 임시 폴더에 저장했다.

## 검수와 남은 작업

실행: 원문 텍스트 추출·페이지 이미지 확인, 로컬 분류 코드 중복/합계 검사, `git ls-files custom_ref`, `git check-ignore`, `scripts/app.cmd run check:docs`, `git diff --check`. 애플리케이션·DB 변경이 없어 앱 테스트·마이그레이션은 실행하지 않았다. 예산 관련 B/W/E 항목은 예정 검수이며 통과로 표시하지 않는다.

결과: 세목 소계 8개와 전체 합계 일치, 세세목 코드 14개 중복 없음. 로컬 Markdown 51개(비공개 참고표 1개 포함)·상대 링크 231개 누락 없음, 공백 오류 없음. 로컬 원문·파생표의 Git 추적 없음 및 제외 적용을 확인했다. 작업 브랜치는 02 완료 `da7b999`에서 분기한 `codex/phase-03-budget-policy`이며 원격 결과 SHA는 작업 보고에 기록한다.

03 구현 전 실제 과제별 배분 및 적용 기간, 신청 복귀 상태·권한을 정리한다. 지급 후 정정/환입·금액 변경·추가/분할 신청의 미답변 정책은 관련 구현 전에 확인한다. 원문에서 정하지 않은 내용을 임의 확정하지 않는다. 03 예산변경의 필수 첨부는 실제 비공개 저장·권한 검수 범위에 포함한다.

02 완료 상태는 유지한다. 03 기능 구현·실예산 DB 입력·main 병합·운영 배포·Notion 변경은 수행하지 않았다.
